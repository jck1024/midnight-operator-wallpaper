SYNTHETIC AUDIO CHECKS
----------------------
Source: 128 frequency bins (64 left and 64 right), fed to genuine callback
code using plausible frequency profiles and PEAK of 0.01--0.05.
At defaults (125 sensitivity, 125 intensity, 125 bass), after adaptation:
  PEAK 0.01 -> average bar ~0.307, maximum ~0.536
  PEAK 0.02 -> average bar ~0.443, maximum ~0.773
  PEAK 0.03 -> average bar ~0.529, maximum ~0.921
  PEAK 0.05 -> average bar ~0.602, maximum <=1.0
At PEAK below 0.004 the silence gate prevents false response.
Tests also verified capped output, monotonic increase with settings,
and decay to near-idle after input becomes quiet or stops.
These values reflect test signals, NOT observed Spotify values.
